# Architecture

Use `profiles/architecture.json`. [ISO/IEC/IEEE 42010:2022](https://www.iso.org/standard/74393.html) defines architecture-description concepts but does not prescribe graphical notation.

Declare viewpoint, concerns, model kind, element types, and relationship legend. Automated validation can prove declared containment, relationship types, endpoint integrity, and visual geometry; it cannot infer the viewpoint from appearance.

Use `assets/templates/topology-landscape.xml` as a provider-neutral boundary scaffold.
